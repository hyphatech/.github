## Hypha Stack

**Components made to fit together.** Designed from the ground up for agents
and people to build software that matters. Open source, MIT.

| | | |
|---|---|---|
| **HTTP and APIs** | Fast, ergonomic and RFC-strict. Eio-native and multicore by design. | [Spindle](https://github.com/hyphatech/spindle) |
| **Data contracts** | Strict, light and derived from your types. Built for JSON Schema, Zod and Melange. | [Wiretype](https://github.com/hyphatech/wiretype) |
| **Data and persistence** | Plain SQL, checked against your database. Postgres and SQLite alike. | [Rowtype](https://github.com/hyphatech/rowtype) |
| **Jobs** | Transactional, reliable and testable. Eio-native and multicore-ready. | [Spool](https://github.com/hyphatech/spool) |
| **Front end** | Fast, accessible and reactivity-safe. Kobalte and HeroUI included. | [Solidtype](https://github.com/hyphatech/solidtype) |
