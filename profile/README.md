## Hypha Stack

The components a backend is built from, designed together: one way to
model data, effects and failure across all of them. Open source, MIT.

| | | |
|---|---|---|
| **HTTP and APIs** | An RFC-strict web framework, typed end to end, fast and multi-core by design. | [Spindle](https://github.com/hyphatech/spindle) |
| **Data contracts** | Unified JSON contracts for backend, frontend and agents. Printed as JSON Schema and Zod. | [Wiretype](https://github.com/hyphatech/wiretype) |
| **Data and persistence** | Typed Postgres queries, checked against the database schema, with migrations built in. | [Rowtype](https://github.com/hyphatech/rowtype) |
| **Postgres driver** | A native driver with TLS, pooling and failover. | [postgres-eio](https://github.com/hyphatech/postgres-eio) |
| **Jobs** | A durable job queue in your own Postgres. | [Spool](https://github.com/hyphatech/spool) |
